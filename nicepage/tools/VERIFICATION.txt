VERIFICATION
============

This package is automatically updated by the Chocolatey-AU (Automatic Update) framework.
The installer is not embedded: it is downloaded from the official source at install time and
verified against the SHA256 checksum embedded in the package when it was created.

Package ID: nicepage
Update Mechanism: Automated (DEUS-DEI/ChocoLateYPackages, nicepage/update.ps1)

HOW TO VERIFY THE BINARY:
-------------------------
1. The download URL is in tools\chocolateyinstall.ps1:
   https://get.nicepage.com/Nicepage-{version}-full.exe
   The current version is published by Nicepage in https://get.nicepage.com/latest.yml

2. Download the file and compare its SHA256 checksum with the one in tools\chocolateyinstall.ps1:
   Get-FileHash -Path "path_to_binary" -Algorithm SHA256
