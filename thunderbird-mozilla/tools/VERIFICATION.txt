VERIFICATION
============

This package is automatically updated by the Chocolatey-AU (Automatic Update) framework.
The installer is not embedded: it is downloaded from the official source at install time and
verified against the SHA256 checksum embedded in the package when it was created.

Package ID: thunderbird-mozilla
Update Mechanism: Automated (DEUS-DEI/ChocoLateYPackages, thunderbird-mozilla/update.ps1)

HOW TO VERIFY THE BINARY:
-------------------------
1. The installer is chosen at install time (language and architecture). URL template:
   https://download-installer.cdn.mozilla.net/pub/thunderbird/releases/{version}/{arch}/{lang}/Thunderbird%20Setup%20{version}.exe

2. tools\checksums.txt contains the Windows lines of Mozilla's official manifest, unchanged:
   https://download-installer.cdn.mozilla.net/pub/thunderbird/releases/{version}/SHA256SUMS
   Download the file and compare its checksum with the matching line:
   Get-FileHash -Path "path_to_binary" -Algorithm SHA256
