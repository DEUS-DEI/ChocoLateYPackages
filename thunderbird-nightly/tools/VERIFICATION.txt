VERIFICATION
============

This package is automatically updated by the Chocolatey-AU (Automatic Update) framework.
The installer is not embedded: it is downloaded from the official source at install time and
verified against the SHA256 checksum embedded in the package when it was created.

Package ID: thunderbird-nightly
Update Mechanism: Automated (DEUS-DEI/ChocoLateYPackages, thunderbird-nightly/update.ps1)

HOW TO VERIFY THE BINARY:
-------------------------
1. The installer is chosen at install time (language and architecture) from the dated (immutable)
   folders of one nightly build. $baseUrl and $version are in tools\chocolateyinstall.ps1:
   {baseUrl}/{yyyy-MM-dd-HH-mm-ss}-comm-central/thunderbird-{version}.en-US.{arch}.installer.exe
   {baseUrl}/{yyyy-MM-dd-HH-mm-ss}-comm-central-l10n/thunderbird-{version}.{lang}.{arch}.installer.exe

2. tools\checksums.txt contains the sha256 lines of Mozilla's official manifest of each installer
   (same folder and name, with the .checksums extension instead of .installer.exe).
   Download the file and compare its checksum with the matching line:
   Get-FileHash -Path "path_to_binary" -Algorithm SHA256
